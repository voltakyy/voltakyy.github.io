# 🏛️ Ruang Belajar Informatika UMS — Super-App Portal

Portal web terpadu satu pintu (*Super-App*) untuk mengakses seluruh materi kuliah, modul persiapan ujian, bank soal interaktif, dan arena simulasi ujian tengah semester (UTS) mahasiswa **Program Studi Informatika, Universitas Muhammadiyah Surakarta (UMS)**.

Dibuat oleh **Rizky ([@voltakyy](https://github.com/voltakyy))** berkolaborasi bersama **Bima (Ketua Kelas B)** dan rekan-rekan mahasiswa angkatan Informatika UMS.

## 🎨 Karakteristik & Desain Sistem

- **Tema Desain:** *Studio Paper Neo-Brutalism* — palet warna kertas hangat (`#f6f0e4`), border tegas `2.5px solid #24221f`, aksen warna-warni ceria, dan bayangan solid `4px 4px 0 #24221f`.
- **Gojek-Style Service Menu:** Deretan ikon layanan empuk (*tactile press animation*) untuk peluncuran matkul cepat dalam 1 klik.
- **Pencarian Real-Time & Filter Kategori:** Cari topik secara instan dengan shortcut keyboard `/` atau filter kategori matkul.
- **PWA Ready:** Dapat dipasang (*Install / Add to Home Screen*) di layar smartphone teman-teman bak aplikasi asli.
- **Ringan & Cepat:** Dibuat menggunakan Native HTML5, CSS3 Modern (Container Queries, Subgrid fallbacks, Flexbox), dan Vanilla JavaScript tanpa framework berat.
