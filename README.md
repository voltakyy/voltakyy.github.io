# 🏛️ Ruang Belajar Informatika UMS — Super-Monorepo Portal

Portal web terpadu satu pintu (*Super-App*) untuk mengakses seluruh materi kuliah, modul persiapan ujian, bank soal interaktif, dan arena simulasi Ujian Tengah Semester (UTS) mahasiswa **Program Studi Informatika, Universitas Muhammadiyah Surakarta (UMS)**.

Dibuat oleh **Rizky ([@voltakyy](https://github.com/voltakyy))** berkolaborasi bersama **Bima (Ketua Kelas B)** dan rekan-rekan angkatan Informatika UMS.

🌐 **Akses Live Portal:** **[https://voltakyy.github.io/](https://voltakyy.github.io/)**

## 🎨 Karakteristik & Desain Sistem

- **Desain:** *Tactile Academic Studio Paper* — palet warna kertas hangat (`#f6f1e8`), batas tegas `2px solid #24221f`, aksen fungsional, dan bayangan tegas `3px 3px 0 #24221f`.
- **Universal Portal Bar:** Setiap modul memiliki bilah navigasi seragam di bagian paling atas untuk kembali ke beranda atau berpindah ke matkul lain dalam 1 klik.
- **Pencarian Real-Time & Filter Kategori:** Cari topik secara instan dengan shortcut keyboard `/` atau filter kategori matkul.
- **Dark Mode Support:** Mode malam yang nyaman untuk belajar larut malam.
- **Zero AI-Slop & Zero-Dependency:** 100% Native HTML5, Modern CSS3, dan Vanilla JavaScript tanpa dependensi framework berat.
