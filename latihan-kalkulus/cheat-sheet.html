01

blok 01 · pertidaksamaan

Pertidaksamaan mencari kumpulan x, bukan satu angka.

Kalau persamaan biasanya berakhir dengan satu nilai, pertidaksamaan berakhir dengan sebuah wilayah di garis bilangan. Tugasmu: temukan batas-batasnya, lalu putuskan batas itu ikut atau tidak.

Aturan emas. Apa pun yang kamu lakukan ke satu bagian, lakukan ke semua bagian. Arah tanda tetap aman selama kamu tidak mengali atau membagi dengan bilangan negatif. Kalau itu terjadi, arah tanda dibalik.
contoh 1

Linear bertingkat: tiga ruas, satu gerakan.

Tentukan himpunan penyelesaian dari −5 ≤ 2x + 6 < 4.

  1. Baca sebagai satu rantai. Artinya dua syarat sekaligus: −5 ≤ 2x+6 dan 2x+6 < 4. Kamu boleh mengerjakan ketiga bagian (kiri, tengah, kanan) sekaligus.

  2. Kurangi 6 di ketiga bagian. Tujuannya mengisolasi 2x.

    −5 − 6 ≤ 2x + 6 − 6 < 4 − 6
    −11 ≤ 2x < −2

  3. Bagi 2 di ketiga bagian. Karena 2 positif, arah tanda tidak berubah.

    −11/2 ≤ x < −2/2
    −11/2 ≤ x < −1

  4. Terjemahkan ke interval. Batas kiri memakai ≤, jadi ikut: [. Batas kanan memakai <, jadi tidak ikut: ).

    HP = [−11/2, −1)

Cek cepat. Ambil x = −3: 2(−3)+6 = 0, dan −5 ≤ 0 < 4 benar. Ambil x = −1: 2(−1)+6 = 4, dan 4 < 4 salah—memang −1 tidak ikut. Ambil x = −11/2: 2(−11/2)+6 = −5, dan −5 ≤ −5 benar—batas kiri ikut.

Jebakan. Berhenti di −11 ≤ 2x < −2 berarti belum selesai: yang diminta adalah x, bukan 2x. Kalau di langkah berikutnya kamu membagi dengan bilangan negatif, misalnya −2x < 6, hasilnya x > −3—tandanya berbalik.

contoh 2

Kuadrat: satu ruas nol, lalu uji tanda.

Tentukan himpunan penyelesaian dari x² − x − 6 < 0.

  1. Pastikan ruas kanan sudah nol. Di soal ini sudah. Kalau belum, pindahkan semua suku ke kiri lebih dulu. Membandingkan dengan nol adalah kunci untuk memakai uji tanda.

  2. Faktorkan. Cari dua bilangan yang hasil kalinya −6 dan jumlahnya −1, yaitu −3 dan +2.

    x² − x − 6 = (x − 3)(x + 2)

    Jadi pertidaksamaannya menjadi (x − 3)(x + 2) < 0.

  3. Tandai akar-akarnya. Akar terjadi saat tiap faktor nol: x = 3 dan x = −2. Karena tandanya < (bukan ≤), kedua akar tidak ikut.

  4. Uji tanda di tiap daerah. Kamu hanya perlu satu titik uji per daerah.

    Geser tabel ke samping bila perlu.

    Uji tanda (x − 3)(x + 2)
    DaerahUji xx − 3x + 2HasilMasuk?
    x < −2−3−−+Tidak
    −2 < x < 30−+−Ya
    x > 34+++Tidak

    Aturan tandanya: (−)·(−) = +, (+)·(+) = +, dan (+)·(−) = −.

  5. Ambil daerah yang hasilnya negatif. Karena soalnya < 0, jawabannya daerah yang bertanda −.

    HP = {x | −2 < x < 3} = (−2, 3)

Cek cepat. x = 0 memberi 0²−0−6 = −6 < 0, benar. x = 3 memberi 0 < 0, salah—jadi 3 tidak ikut. x = −2 juga memberi 0, jadi −2 tidak ikut.

Jebakan. Jangan menulis x < −2 atau x < 3. Itu bukan cara membaca tabel. Tabel menunjukkan tiga daerah terpisah; yang memenuhi hanya daerah tengah. Kalau tandanya ≤, akar ikut dan jawabannya [−2, 3].

Kalau a < 0. Pada contoh di atas, koefisien x² positif (a = 1), sehingga hasilnya + di luar akar dan − di antara akar. Kalau a < 0, jangan menghafal pola terbaliknya—kalikan seluruh pertidaksamaan dengan −1 dan balik arah tandanya, lalu faktorkan. Contoh: −x² + x + 6 > 0 ⇒ x² − x − 6 < 0 ⇒ (x − 3)(x + 2) < 0 ⇒ −2 < x < 3.

contoh 3

Nilai mutlak: jarak, bukan tanda minus.

Tentukan himpunan penyelesaian dari |2x − 1| ≤ 5.

Baca sebagai jarak. |A| adalah jarak A dari 0. Jadi |A| ≤ 5 berarti A tidak lebih jauh dari 5 satuan dari 0: −5 ≤ A ≤ 5.

  1. Ganti bentuk mutlaknya.

    −5 ≤ 2x − 1 ≤ 5

  2. Tambahkan 1 di ketiga bagian.

    −4 ≤ 2x ≤ 6

  3. Bagi 2. Positif, jadi tanda tidak berubah.

    −2 ≤ x ≤ 3

  4. Tulis interval. Kedua batas memakai ≤, jadi keduanya ikut.

    HP = [−2, 3]

Cek cepat. x = −2: |−5| = 5 ≤ 5 benar. x = 3: |5| = 5 ≤ 5 benar. x = 4: |7| = 7 ≤ 5 salah.

Jebakan. |2x−1| ≤ 5 bukan berarti 2x−1 ≤ 5 saja. Tanpa batas kiri, kamu kehilangan separuh jawaban.

contoh 4

Nilai mutlak “lebih besar”: pecah jadi dua cabang.

Tentukan himpunan penyelesaian dari |x + 1| > 3.

Baca sebagai jarak. |A| > 3 berarti A lebih dari 3 satuan dari 0, ke kiri atau ke kanan. Karena itu hasilnya dua cabang yang digabung dengan atau.

  1. Pecah menjadi dua pertidaksamaan.

    x + 1 < −3   atau   x + 1 > 3

  2. Selesaikan masing-masing.

    x < −4   atau   x > 2

  3. Tulis sebagai gabungan interval. Kedua tanda tegas, jadi kedua batas tidak ikut. Ingat, ±∞ selalu memakai kurung biasa karena tak ada bilangan yang bisa dimasukkan.

    HP = (−∞, −4) ∪ (2, ∞)

Cek cepat. x = −5: |−4| = 4 > 3 benar. x = 0: |1| = 1 > 3 salah—0 memang di daerah kosong. x = 3: |4| = 4 > 3 benar.

Jebakan. Jangan menulis −3 < x + 1 < 3; itu bentuk untuk |...| < 3. Untuk >, hasilnya justru di luar kedua batas. Kata “atau” berarti gabungan (∪), bukan irisan (∩).

Rangkuman 01

  • Linear: kerjakan semua ruas; ×/÷ negatif membalik tanda.
  • Kuadrat: nol di kanan → faktor → akar → tabel tanda.
  • |A| < a: di antara −a dan a (dan). |A| > a: di luar −a dan a (atau).
  • Selalu ubah hasil akhir ke notasi interval dan uji satu titik.

02

blok 02 · fungsi kuadrat

Parabola cuma punya lima informasi penting.

Hampir semua soal fungsi kuadrat meminta satu dari lima hal: arah buka, vertex, akar, potong sumbu-y, atau range. Kalau kelimanya sudah ditandai, sketsa dan domain–range jadi jauh lebih mudah.

Bentuk yang paling berguna. y = a(x − xv)² + yv. Dari sini kamu bisa membaca vertex (xv, yv) langsung, dan tanda a memberi tahu arah buka.

xv = −b/(2a)  ·  yv = f(xv) = c − b²/(4a)
D = b² − 4ac  ·  x = (−b ± √D)/(2a)

contoh 1

Contoh lengkap: y = x² + 5x + 6.

  1. Baca koefisiennya. a = 1, b = 5, c = 6. Karena a > 0, parabola terbuka ke atas dan vertex-nya adalah titik minimum.

  2. Cari sumbu simetri (x vertex).

    xv = −b/(2a) = −5/(2·1) = −5/2

  3. Cari y vertex. Masukkan xv ke fungsi; jangan pakai rumus yang salah.

    yv = f(−5/2) = 25/4 − 25/2 + 6
    = 25/4 − 50/4 + 24/4 = −1/4

    Jadi vertex-nya (−5/2, −1/4).

  4. Cari akar-akarnya. Diskriminan menentukan banyak akar.

    D = b² − 4ac = 25 − 24 = 1 > 0
    x = (−5 ± 1)/2 ⇒ x = −2 atau x = −3

    Jadi parabola memotong sumbu-x di (−3, 0) dan (−2, 0).

  5. Tambahkan potong sumbu-y dan titik cerminnya. Saat x = 0, y = 6, jadi (0, 6). Karena sumbu simetri x = −5/2, titik cerminnya adalah (−5, 6).

  6. Tentukan range. Vertex adalah nilai minimum, dan parabola terbuka ke atas.

    Domain = ℝ
    Range = [−1/4, ∞)

  7. Sketsa dengan urutan ini. Tandai akar −3 dan −2 → vertex (−5/2, −1/4) → potong y (0,6) dan cerminnya (−5,6) → gambar kurva U → labeli sumbu x = −5/2.

Cek cepat. Vertex harus berada di tengah kedua akar: (−3 + (−2))/2 = −5/2, cocok. Dan f(−5/2) = 25/4 − 25/2 + 6 = −1/4, cocok.

Jebakan. xv = −b/(2a), bukan b/(2a). Lalu yv adalah nilai fungsi di xv, bukan sumbu simetrinya. Range memakai yv, bukan akar.

contoh 2

Kalau a < 0: parabola terbalik, range ikut terbalik.

Tentukan vertex, akar, dan range dari y = −x² + 2x + 3.

  1. Baca koefisiennya. a = −1, b = 2, c = 3. Karena a < 0, parabola terbuka ke bawah dan vertex-nya maksimum.

  2. Cari vertex.

    xv = −2/(2·(−1)) = 1
    yv = −(1)² + 2(1) + 3 = 4

    Vertex: (1, 4).

  3. Cari akar. Kalikan dulu dengan −1 agar lebih mudah difaktorkan.

    −x² + 2x + 3 = 0
    x² − 2x − 3 = 0
    (x − 3)(x + 1) = 0
    x = 3 atau x = −1

  4. Potong sumbu-y dan titik cermin. f(0) = 3, jadi (0,3). Sumbu simetri x = 1, jadi cerminnya (2,3).

  5. Tentukan range. Nilai maksimum 4, terbuka ke bawah.

    Domain = ℝ
    Range = (−∞, 4]

Cek cepat. f(1) = −1 + 2 + 3 = 4. f(3) = −9 + 6 + 3 = 0. f(0) = 3. Semua cocok dengan sketsa ∩ yang melewati (−1,0), (3,0), dan puncak (1,4).

Jebakan. Saat a < 0, range-nya (−∞, yv], bukan [yv, ∞). Saat mengalikan persamaan dengan −1, semua suku berubah tanda—jangan hanya suku tengahnya.

contoh 3

Domain: akar dan penyebut harus damai.

Tentukan domain dari f(x) = √(x − 2) / (x − 5).

  1. Syarat akar genap. Isi di dalam akar tidak boleh negatif.

    x − 2 ≥ 0 ⇒ x ≥ 2

    Tanda ≥ dipakai karena akar 0 masih boleh.

  2. Syarat penyebut. Penyebut tidak boleh nol.

    x − 5 ≠ 0 ⇒ x ≠ 5

  3. Iriskan kedua syarat. Di garis bilangan: titik 2 masuk (bulat penuh), titik 5 bolong.

    Domain = [2, 5) ∪ (5, ∞)

Cek cepat. x = 2: √0/(−3) = 0, terdefinisi. x = 5: penyebut 0, tidak boleh. x = 4: √2/(−1), terdefinisi. x = 6: √4/1 = 2, terdefinisi.

Jebakan. Domain hanya menjawab “x mana yang boleh masuk”. Range menjawab “nilai y apa yang keluar”—dua hal berbeda. Jangan menulis range = kodomain tanpa memeriksa output yang benar-benar tercapai. Untuk log, syaratnya lebih ketat: isi log harus > 0, bukan ≥ 0.

Catatan lanjut (kalau ditanya range). Untuk 2 ≤ x < 5, pembilang ≥ 0 dan penyebut < 0, jadi f(x) ≤ 0; nilainya turun menuju −∞ saat x → 5⁻. Untuk x > 5, f(x) > 0; nilainya turun dari +∞ menuju 0 tanpa menyentuh 0. Gabungan kedua cabang itu adalah seluruh ℝ. Ini bukan dibaca dari domain—harus dianalisis dari nilai fungsinya.

Rangkuman 02

  • a > 0: U, minimum, range [yv, ∞).
  • a < 0: ∩, maksimum, range (−∞, yv].
  • Vertex: xv = −b/(2a), lalu hitung yv = f(xv).
  • Sketsa: akar → vertex → potong y → sumbu simetri → arah buka.
  • Domain: penyebut ≠ 0, isi akar genap ≥ 0, isi log > 0.

03

blok 03 · fungsi, invers, komposisi

Fungsi itu mesin: input masuk, output keluar. Invers membalik mesinnya.

Tiga istilah yang sering tertukar: domain (apa yang boleh masuk), kodomain (tempat output “ditujukan”), dan range (output yang benar-benar keluar). Invers hanya ada kalau mesinnya bisa dibalik dengan pasti.

Definisi paling dasar: fungsi memasangkan setiap input di domain ke tepat satu output. Kalau satu input punya dua output berbeda, itu bukan fungsi.

Domain Semua input yang boleh masuk. f(x) = x² → ℝ
Kodomain Himpunan tempat output ditujukan. f: ℝ → ℝ, kodomain = ℝ
Range Output yang benar-benar muncul. f(x) = x² → [0, ∞)

Pada contoh f(x) = x² dengan domain ℝ dan kodomain ℝ, range-nya hanya [0, ∞). Karena range ≠ kodomain, fungsi itu belum surjektif ke ℝ. Kalau kodomainnya diubah menjadi [0, ∞), barulah surjektif.

contoh 1

Invers: selesaikan x, baru tukar variabel.

Tentukan invers dari f(x) = (2x + 3) / (x − 1), lalu tuliskan domain dan range-nya.

  1. Tulis y = f(x) dan catat syarat awal. Penyebut tidak boleh nol.

    y = (2x + 3)/(x − 1),   x ≠ 1

  2. Kalikan silang. Tujuannya menghilangkan pecahan.

    y(x − 1) = 2x + 3
    yx − y = 2x + 3

  3. Kumpulkan semua x di satu ruas.

    yx − 2x = y + 3
    x(y − 2) = y + 3

  4. Bagi dengan (y − 2). Di sini muncul syarat baru: y ≠ 2.

    x = (y + 3)/(y − 2),   y ≠ 2

  5. Baru sekarang tukar x dan y.

    f−1(x) = (x + 3)/(x − 2),   x ≠ 2

  6. Tentukan domain dan range. Domain f adalah semua x kecuali 1. Range f adalah semua y kecuali 2, karena y = 2 tidak punya solusi: 2x + 3 = 2(x − 1) menghasilkan 3 = −2, mustahil.

    Domain f = ℝ \ {1}
    Range f = ℝ \ {2}
    Domain f−1 = ℝ \ {2}
    Range f−1 = ℝ \ {1}

Cek cepat. f(0) = −3, dan f−1(−3) = 0. f(2) = 7, dan f−1(7) = 2. Bisa juga cek f(f−1(x)) = x: hasilnya memang x, selama x ≠ 2.

Jebakan. f−1(x) bukan 1/f(x). Dan jangan menukar x dengan y sebelum menyelesaikan x—kamu akan mengerjakan persamaan yang salah. Selalu tulis syarat penyebut di akhir.

contoh 2

Komposisi: kerjakan dari dalam ke luar.

Diketahui f(x) = 2x + 1 dan g(x) = x². Tentukan (f∘g)(x) dan (g∘f)(x).

  1. Baca notasi. (f∘g)(x) = f(g(x)): masukkan x ke g dulu, lalu hasilnya ke f.

  2. Hitung f∘g.

    (f∘g)(x) = f(g(x)) = f(x²)
    = 2(x²) + 1 = 2x² + 1

  3. Hitung g∘f. Sekarang urutannya terbalik: f dulu, baru g.

    (g∘f)(x) = g(f(x)) = g(2x + 1)
    = (2x + 1)² = 4x² + 4x + 1

  4. Bandingkan hasilnya. Keduanya berbeda, jadi urutan komposisi tidak boleh dibalik.

(f∘g)(x)

2x² + 1

g dulu, lalu f.

(g∘f)(x)

4x² + 4x + 1

f dulu, lalu g.

Cek cepat dengan angka. Ambil x = 2. f(g(2)) = f(4) = 9, sedangkan g(f(2)) = g(5) = 25. Jelas berbeda. Ingat juga: (f∘g)(x) bukan f(x)·g(x); untuk x = 2, hasil perkaliannya 5·4 = 20.

Jebakan. Jangan menjawab f(g(x)) = 2x + 1 dengan mengganti x menjadi x² hanya di sebagian tempat. Ganti seluruh x pada f dengan g(x).

contoh 3

Domain komposisi: dua pintu yang harus dilewati.

Diketahui f(x) = 1/x dan g(x) = √(x − 1). Tentukan domain dari h(x) = (f∘g)(x).

  1. Susun fungsinya.

    h(x) = f(g(x)) = 1/√(x − 1)

  2. Syarat dari g. Isi akar tidak boleh negatif.

    x − 1 ≥ 0 ⇒ x ≥ 1

  3. Syarat dari f. Input f adalah √(x − 1), dan f tidak boleh menerima 0.

    √(x − 1) ≠ 0 ⇒ x − 1 ≠ 0 ⇒ x ≠ 1

  4. Gabungkan. x ≥ 1 tetapi x ≠ 1, sehingga yang tersisa hanya x > 1.

    Domain h = (1, ∞)

Cek cepat. x = 2: h(2) = 1/√1 = 1, terdefinisi. x = 1: penyebut 0, tidak boleh. x = 0: akar negatif, tidak boleh.

Jebakan. Domain komposisi bukan hanya domain g. Kamu juga harus memastikan output g masuk ke domain f. Dua syarat, lalu diiris.

contoh 4

Invers komposisi: buka mesin dari belakang.

Masih dengan f(x) = 2x + 1 dan g(x) = x², tetapi sekarang domain g dibatasi x ≥ 0. Tentukan (f∘g)−1(x) dan bandingkan dengan g−1∘f−1.

  1. Hitung f∘g lebih dulu. Dengan x ≥ 0:

    (f∘g)(x) = f(x²) = 2x² + 1

    Domainnya [0, ∞), range-nya [1, ∞).

  2. Selesaikan inversnya. Misalkan y = 2x² + 1.

    y − 1 = 2x²
    x² = (y − 1)/2
    x = √((y − 1)/2)

    Ambil akar positif karena x ≥ 0. Jadi (f∘g)−1(x) = √((x − 1)/2) dengan x ≥ 1.

  3. Hitung lewat rumus g−1∘f−1. Pada domain x ≥ 0, g−1(x) = √x dan f−1(x) = (x − 1)/2.

    (g−1∘f−1)(x) = g−1((x − 1)/2)
    = √((x − 1)/2)

    Syaratnya (x − 1)/2 ≥ 0, yaitu x ≥ 1. Hasilnya sama.

  4. Pahami urutannya. Untuk membalik f∘g, buka dulu f (yang terakhir dipasang), lalu g. Itulah kenapa urutannya g−1∘f−1, bukan sebaliknya.

Cek cepat. (f∘g)(2) = 2(4)+1 = 9. Inversnya: √((9−1)/2) = √4 = 2, kembali ke input awal.

Jebakan. (f∘g)−1 = g−1∘f−1, bukan f−1∘g−1. Urutan dibalik karena mesin terakhir harus dibongkar lebih dulu.

Rangkuman 03

  • Domain = input yang boleh; kodomain = tujuan; range = output nyata. Range ≠ kodomain.
  • Invers: y = f(x) → selesaikan x → tukar x dan y → tulis syarat.
  • Komposisi: (f∘g)(x) = f(g(x)); kerjakan g dulu. Urutan tidak boleh dibalik.
  • Domain komposisi: syarat dari fungsi dalam + syarat dari fungsi luar, lalu diiris.
  • Invers komposisi: (f∘g)−1 = g−1∘f−1.
