Cheatsheet & Kamus Sintaks GvRng Lengkap

Panduan ringkas instruksi dasar, struktur kontrol Python-style, dan semua sensor pendeteksi dinding serta beeper.

1. Perintah Dasar Robot

InstruksiKeterangan
moveMelangkah 1 petak ke depan sesuai arah hadap
turnleftMemutar badan 90° berlawanan arah jarum jam
pickbeeperMemungut 1 beeper dari petak saat ini
putbeeperMenaruh 1 beeper dari tas ke petak saat ini
turnoffMematikan robot dan mengakhiri program

2. Sensor Dinding & Rintangan

SensorBernilai True Jika...
front_is_clearDi depan robot TIDAK ada dinding
front_is_blockedDi depan robot TERHALANG dinding
left_is_clearDi sisi kiri robot tidak ada dinding
left_is_blockedDi sisi kiri robot terhalang dinding
right_is_clearDi sisi kanan robot tidak ada dinding
right_is_blockedDi sisi kanan robot terhalang dinding

3. Sensor Beeper & Orientasi

SensorKeterangan
next_to_a_beeperAda minimal 1 beeper di petak robot
not_next_to_a_beeperTidak ada beeper di petak robot
any_beepers_in_beeper_bagTas robot memiliki minimal 1 beeper
no_beepers_in_beeper_bagTas beeper robot kosong
facing_northRobot sedang menghadap ke Utara
facing_southRobot sedang menghadap ke Selatan
facing_eastRobot sedang menghadap ke Timur
facing_westRobot sedang menghadap ke Barat

4. Blok Kontrol & Fungsi

SintaksContoh Format
define 
define turnright:
    turnleft
    turnleft
    turnleft
do <n>: 
do 4:
    move
while <kondisi>: 
while front_is_clear:
    move
if / elif / else: 
if next_to_a_beeper:
    pickbeeper
else:
    move

5. Trik Hemat Baris & Efisiensi Energi Praktikum

Belok Kanan Elegan (4 baris): 
define turnright:
    do 3:
        turnleft
Mengambil Beeper Tak Tentu (3 baris): 
while next_to_a_beeper:
    pickbeeper
Hemat Energi Fisik (Buku Hal 53):

Perhatikan langkah fisik robot. Lebih baik menulis fungsi yang memeriksa dua sisi sekaligus daripada robot harus berputar balik berulang kali.
