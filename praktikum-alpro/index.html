⚡ 2 Definisi Pondasi: turnright & langkah

Wajib di Awal Kode

Karena robot Karel/GvRng secara bawaan hanya memiliki instruksi belok kiri (turnleft), kedua fungsi ini menjadi pondasi wajib untuk menavigasi dinding secara otomatis:

1. Definisi Belok Kanan (turnright) 
define turnright:
    do 3:
        turnleft
Logika Matematika: 1 kali putar kiri = 90°. Putar kiri 3 kali = 270° berlawanan arah jarum jam, yang posisinya persis sama dengan belok kanan 90° searah jarum jam!
2. Definisi Susur Dinding Kiri (langkah) 
define langkah:
    while next_to_a_beeper:
        pickbeeper
    turnleft
    while front_is_blocked:
        turnright
    move
Logika 4 Tahap: 1. Bersihkan koin di petak saat ini → 2. Tengok ke kiri → 3. Jika ada tembok menghadang di depan, putar kanan sampai jalur plong → 4. Maju 1 petak. Bahu kiri robot selalu menempel rapat ke dinding!

🎯 Latihan 1: Lintasan Ular S Zig-Zag (3 Lantai Bertingkat)

Latihan 1 Mandiri • Soal Baru

Robot harus menavigasi lorong gedung 3 lantai yang berkelok seperti huruf S. Ambil beeper di setiap ujung belokan lantai, lalu lari menuju garis finish di lantai teratas (10,3) EAST tanpa perlu menebak atau menghitung langkah manual!

🎮 Visualisator Kanvas 2D & Lintasan Nyata
Lintasan Lengkap (27 Titik)
Start (2,1) Lintasan Gerak & Arah Panah 3 Beeper Lantai Finish (10,3)
💻 Solusi Siswa Cerdas (Pola Moduler Naik Lantai) 
define turnright:
    do 3:
        turnleft

define naik_lantai_kiri:
    turnleft
    move
    turnleft

define naik_lantai_kanan:
    turnright
    move
    turnright

# Lantai 1: Lari ke Timur sampai ujung lorong
while front_is_clear:
    move
pickbeeper

# Naik ke Lantai 2 (putar balik ke Barat)
naik_lantai_kiri

# Lantai 2: Lari ke Barat sampai ujung lorong
while front_is_clear:
    move
pickbeeper

# Naik ke Lantai 3 (putar balik ke Timur)
naik_lantai_kanan

# Lantai 3: Lari ke Timur menuju garis finish
while front_is_clear:
    move
pickbeeper
turnoff
Trik Ujian: Jangan pernah menghitung langkah per petak! Pecah lorong bertingkat menjadi 2 fungsi transisi tangga: naik_lantai_kiri dan naik_lantai_kanan. Di setiap lantai, cukup biarkan sensor while front_is_clear: move meluncur otomatis sampai membentur tembok ujung!

🧩 Pola 2: Mengelilingi 3 Kotak Hambatan (Buku Hal 52)

Misi 7 Resmi • Buku Praktikum Hal 52

Robot mulai dari (2,1) menghadap EAST, harus mengitari 3 kotak rintangan di koordinat (4,2), (7,2), (10,2), menyapu seluruh koin beeper, lalu kembali ke posisi semula (2,1) dan turnoff.

🎮 Visualisator Kanvas 2D & Lintasan Nyata
Lintasan Lengkap (43 Titik)
Start (2,1) Lintasan Gerak & Arah Panah Beeper Tersebar Finish (2,1)
💻 Solusi Moduler Siswa Cerdas (Buku Praktikum) 
define circumference:
    do 4:
        if next_to_a_beeper:
            pickbeeper
        turnleft
        move
        if next_to_a_beeper:
            pickbeeper
        move

# Mengelilingi 3 kotak satu per satu
do 3:
    do 3:
        move
    circumference

# Pulang kembali ke titik start (2,1)
turnleft
turnleft
do 9:
    move
turnleft
turnleft
turnoff
Trik Ujian: Kotak berbentuk bujur sangkar simetris 4 sisi! Cukup buat satu fungsi circumference yang mengitari 4 sisi kotak dengan loop do 4:. Setelah mengitari ketiga kotak, robot cukup putar balik 180° dan lari lurus kembali ke koordinat awal.

🧩 Pola 3: Kamar Bercabang di Koridor (Mampir Ruangan)

Misi 9 Resmi • 9 Baris

Robot berjalan di lorong panjang. Jika mendeteksi pintu ruangan di sebelah kiri, robot harus mampir, mengambil beeper di ujung kamar, putar balik, lalu lanjut berjalan.

🎮 Visualisator Kanvas 2D & Lintasan Nyata
Lintasan Lengkap (32 Titik)
Start (2,2) Lintasan Gerak & Arah Panah Beeper di Ujung Finish (3,3)
💻 Solusi Siswa Cerdas (Kombinasi while + if/else) 
while not_next_to_a_beeper:
    if left_is_clear:
        turnleft
    if front_is_clear:
        move
    else:
        turnleft

pickbeeper
turnoff
Trik Ujian: Hanya butuh 9 baris! Sensor left_is_clear otomatis mendeteksi pintu kamar, dan else: turnleft otomatis memutar robot saat menabrak dinding di ujung kamar tanpa tebak langkah.
