# Praktikum Algoritma & Pemrograman (Alpro) — GvRng Interactive Arena & Quiz

Website modul mandiri, arena visualisasi labirin interaktif, dan kuis pemahaman logika pemrograman **Guido van Robot Next Generation (GvRng)** untuk mahasiswa Informatika Universitas Muhammadiyah Surakarta.

## Fitur Utama
1. **Interactive Step-by-Step Maze Runner (Grid Visualizer)**
   - Eksekusi kode GvRng langkah demi langkah (*step-by-step*) dengan visual code line highlighter.
   - Peta interaktif dari soal Quiz Dasprog B dan Quiz Aslab (Spiral, Lorong Bertingkat, Papan Catur, dll).
2. **Kuis Interaktif Logika GvRng**
   - Latihan soal tebak arah, koordinat akhir, sensor kondisi, loop `while`/`do`, dan optimasi baris kode.
   - Instant feedback dan pembahasan detail.
3. **Arsip Pembahasan Soal Resmi**
   - Pembahasan detail soal ujian Quiz Dasprog B, Quiz Aslab, dan Ujian Jangka Panjang.
4. **Cheatsheet & Kamus Sensor GvRng**
   - Panduan lengkap sintaks, sensor, struktur blok, dan best practice efisiensi baris kode.
