"Apa itu Class? Dan apa itu Object?
Berikan penjelasan beserta dengan contohnya!"

Kunci Jawaban Sempurna (Sesuai Modul SPADA UMS P3 & P4)

1. Pengertian Class (Blueprint / Template)

Berdasarkan modul resmi SPADA UMS Pertemuan 3 & 4: Class adalah sebuah blueprint (cetak biru) atau template yang mendefinisikan struktur data (property) dan perilaku (method) yang dimiliki oleh objek. Class belum memiliki wujud fisik di memori komputer sebelum objek di-instansiasi.

Representasi di Alice 3: Class terletak di bagian Gallery (contoh: Class Robot, Class Bunny, atau Class Penguin).

Analogi: Denah arsitektur rumah atau resep kue martabak. Denah tersebut memuat ukuran dan rancangan ruangan, tetapi belum bisa ditinggali karena belum berwujud fisik.

2. Pengertian Object (Instance)

Object adalah instance (wujud nyata) konkret yang diciptakan berdasarkan sebuah class (prinsip One Class, Many Objects). Ketika sebuah object dibuat (menggunakan operator new pada Java atau ditempatkan di Scene pada Alice 3), ruang memori komputer dialokasikan untuk menyimpan nilai-nilai property objek tersebut.

Representasi di Alice 3: Objek berada di dalam Scene. Dari 1 Class Bunny di Gallery, kita dapat membuat objek bunny dan bunny2 di Scene dengan nilai posisi, orientasi, atau warna yang berbeda (Same Class, Different Objects).

Analogi: Rumah nyata yang sudah dibangun dari denah, atau kue martabak matang yang siap dimakan.

3. Contoh Riil dalam Kode

Contoh OOP Java / Alice 3 Concept 
// 1. CLASS (Cetak Biru)
class Mobil {
    String merk;
    String warna;
    int kecepatan;

    void maju() {
        kecepatan += 10;
        System.out.println(merk + " melaju cepat!");
    }
}

// 2. OBJECT (Wujud Nyata di Memori)
public class Main {
    public static void main(String[] args) {
        // Objek 1
        Mobil mobilAvanza = new Mobil();
        mobilAvanza.merk = "Toyota Avanza";
        mobilAvanza.warna = "Hitam";
        mobilAvanza.maju();

        // Objek 2 (Dibuat dari Class yang sama, data berbeda)
        Mobil mobilBrio = new Mobil();
        mobilBrio.merk = "Honda Brio";
        mobilBrio.warna = "Kuning";
    }
}
Aspek Penilaian Poin Maks Kriteria
Definisi Class 6 Poin Menyebut blueprint/cetak biru, mendefinisikan atribut & method.
Definisi Object 6 Poin Menyebut instance/wujud nyata, menempati memori dengan keyword new.
Contoh & Analogi 8 Poin Menyertakan contoh class dan minimal 1-2 objek konkret yang jelas.

Kunci Jawaban Sempurna (Sesuai Modul SPADA UMS P3 & P4)

1. Perbedaan Property dan Method

  • Property (Data / Keadaan / State): Data atau keadaan yang dimiliki oleh sebuah object yang menunjukkan "apa yang dimiliki (what it has)". Pada Alice 3, property dikelola di Panel Properties (contoh: color, position, orientation, size, speed). Nilai property dapat berbeda antar-objek dan dapat berubah selama program berjalan.
  • Method (Perilaku / Aksi / Behavior): Tindakan atau aksi yang dapat dilakukan oleh sebuah object yang menunjukkan "apa yang dapat dilakukan (what it does)". Pada Alice 3, method disusun di Code Editor (contoh: move(), turn(), stop(), say(), jump()). Method dapat menerima parameter untuk menghasilkan behavior tertentu.

2. Implementasi Class: KarakterGame (4 Property & 4 Method)

Berikut adalah contoh class yang memenuhi kriteria soal secara presisi:

KarakterGame.java (4 Property & 4 Method) 
public class KarakterGame {
    // ==========================================
    // 4 PROPERTY (Atribut / Data Karakter)
    // ==========================================
    String nama;              // Property 1: Nama karakter
    int nyawa;                // Property 2: Poin kesehatan (HP)
    int level;                // Property 3: Tingkatan karakter
    int kekuatanSerang;       // Property 4: Besaran damage serangan

    // ==========================================
    // 4 METHOD (Aksi / Perilaku Karakter)
    // ==========================================
    // Method 1: Menyerang target lawan
    void serangMusuh(String target) {
        System.out.println(nama + " menebas " + target + " sebesar " + kekuatanSerang + " damage!");
    }

    // Method 2: Menerima pengurangan nyawa
    void terimaDamage(int damage) {
        nyawa -= damage;
        if (nyawa < 0) nyawa = 0;
        System.out.println(nama + " terkena hit! Sisa nyawa: " + nyawa);
    }

    // Method 3: Memulihkan nyawa dengan ramuan
    void minumPotion(int heal) {
        nyawa += heal;
        System.out.println(nama + " meminum potion. Nyawa bertambah menjadi: " + nyawa);
    }

    // Method 4: Menaikkan level dan status
    void naikLevel() {
        level += 1;
        kekuatanSerang += 15;
        System.out.println("LEVEL UP! " + nama + " kini Level " + level);
    }
}
Komponen Jawaban Target Minimum Status Pemenuhan
Definisi Property & Method Konsep jelas Dijelaskan sebagai karakteristik (state) vs aksi (behavior).
Jumlah Property Minimal 4 4 Terpenuhi: nama, nyawa, level, kekuatanSerang.
Jumlah Method Minimal 4 4 Terpenuhi: serangMusuh(), terimaDamage(), minumPotion(), naikLevel().

Kunci Jawaban Sempurna (100% Nilai Penuh)

1. Analisis Redundansi (Atribut & Method Bersama)

Jika kita amati ketiga diagram pada soal sebelum inheritance:

  • Atribut yang sama persis di ke-3 class: nama, usia, gender, alamat.
  • Method yang sama persis di ke-3 class: berjalan(), makan().

2. Pembentukan Parent Class (Superclass)

Kita ciptakan satu Parent Class bernama: Manusia (atau Orang / Person).

  • Property Parent (Manusia): + nama, + usia, + gender, + alamat
  • Method Parent (Manusia): + berjalan(), + makan()

3. Spesialisasi Child Classes (Subclasses)

Ketiga class anak hanya perlu menyimpan atribut dan method yang khas / unik miliknya:

  • Class Mahasiswa (extends Manusia):
    Property unik: + kampus, + prodi, + ipk
    Method unik: + mengerjakanTugas(), + belajar()
  • Class Petani (extends Manusia):
    Property unik: + hasilTani
    Method unik: + bertani()
  • Class Pedagang (extends Manusia):
    Property unik: + penjualan, + toko, + alamatToko
    Method unik: + berdagang(), + menawar()

4. Diagram UML Inheritance Hasil Rekonstruksi

5. Penjelasan Singkat Prinsip Inheritance

Dengan pewarisan, kode menjadi jauh lebih ringkas, efisien, dan terstruktur dengan mematuhi prinsip DRY (Don't Repeat Yourself). Properti umum seperti nama, usia, gender, alamat serta method berjalan(), makan() cukup dideklarasikan satu kali saja di dalam superclass Manusia. Ketiga class turunan (Mahasiswa, Petani, dan Pedagang) secara otomatis mewarisi seluruh kemampuan tersebut lewat relasi "is-a" (seorang Mahasiswa adalah Manusia). Jika di kemudian hari ada penambahan atribut manusia seperti nik, kita cukup mengubah di Manusia tanpa perlu menyentuh ketiga subclass.

Buatlah contoh functions dan procedures (minimal 2)!
(Kamu bisa mengambil contoh dari ALICE 3)"

Kunci Jawaban Sempurna (100% Nilai Penuh)

1. Penjelasan & Perbedaan Mendasar

Dalam Pemrograman Visual (khususnya Alice 3 dan OOP Java), method terbagi menjadi dua kategori utama berdasarkan ada atau tidaknya nilai balik (return value):

Pembeda Procedure (Prosedur) Function (Fungsi)
Nilai Balik (Return Value) TIDAK MENGEMBALIKAN NILAI (bertipe void). MENGEMBALIKAN NILAI (bertipe Boolean, Double, String, Objek, dsb).
Tujuan Utama Melakukan aksi fisik, gerakan animasi, perubahan visual objek, atau suara. Menjawab pertanyaan mengenai kondisi/keadaan objek atau menghitung nilai.
Cara Pemanggilan Dapat berdiri sendiri sebagai satu baris perintah utuh. Harus ditampung ke dalam variabel, dipakai dalam rumus, atau sebagai syarat percabangan (if).
Efek Samping (Side Effects) Mengubah status objek di scene (misal koordinat X/Y/Z, rotasi yaw/pitch). Tidak mengubah status visual objek (hanya query baca data).
Analogi Kehidupan Sehari-hari "Tolong bersihkan papan tulis!" (Perintah aksi nyata). "Berapa sisa spidol di meja?" (Pertanyaan mencari informasi/nilai).

2. Contoh Procedures di ALICE 3 (Minimal 2 Contoh)

  1. this.alice.move(Direction.FORWARD, 2.0);
    Penjelasan: Menggerakkan karakter alice maju ke depan sejauh 2 meter di dunia 3D. Menghasilkan animasi visual langsung tanpa menghasilkan nilai return.
  2. this.alice.say("Selamat datang di UMS!");
    Penjelasan: Menampilkan balon teks percakapan kartun di atas kepala alice. Ini adalah tindakan murni (prosedur) visual.
  3. (Alternatif): this.alice.turn(Direction.RIGHT, 0.25); (Memutar tubuh karakter 90 derajat ke kanan).

3. Contoh Functions di ALICE 3 (Minimal 2 Contoh)

  1. this.alice.getDistanceTo(this.rabbit);
    Penjelasan: Menghitung dan mengembalikan angka desimal (bertipe Double) yang menyatakan jarak antara posisi karakter alice dengan rabbit.
  2. this.alice.getHeight();
    Penjelasan: Mengukur tinggi fisik karakter alice dan mengembalikan nilai angka Double.
  3. (Alternatif): this.alice.isCollidingWith(this.rock); (Mengembalikan nilai logika Boolean: true jika bersentuhan atau false jika tidak).
Penerapan Function di Dalam Percabangan (Alice 3 / Java) 
// Function getDistanceTo() dipakai sebagai syarat kondisi:
if (this.alice.getDistanceTo(this.rabbit) < 1.5) {
    // Procedure say() dipanggil sebagai aksi:
    this.alice.say("Halo kelinci lucu!");
}
SOAL 05 Bobot: 15 Poin CPMK 1 (Perulangan / Looping)

"Apa yang dimaksud dengan perulangan? Berikan contoh implementasinya dan jelaskan!"

Kunci Jawaban Sempurna (Sesuai Modul SPADA UMS P5)

1. Pengertian Perulangan (Looping / Iteration)

Berdasarkan Modul SPADA UMS Pertemuan 5, Perulangan (Loop) adalah struktur kontrol algoritma pemrograman yang digunakan untuk mengeksekusi satu atau sekumpulan instruksi secara berulang-ulang tanpa perlu menuliskan kode yang sama berulang kali:

  • Counted Loop (count up to di Alice 3 / for di Java): Perulangan dengan jumlah iterasi yang sudah diketahui secara pasti sejak awal.
  • Conditional Loop (while di Alice 3 / Java): Perulangan bersyarat yang terus berjalan selama kondisi logika masih bernilai true.
  • Kombinasi dengan Control Statement: Sering digabungkan dengan blok do in order (eksekusi berurutan satu per satu) dan do together (eksekusi simultan bersamaan).

Manfaat Utama: Mencegah duplikasi kode (DRY), menghemat memori, menyederhanakan kode, serta mempermudah otomasi tugas animasi (seperti Bunny melompat berulang kali).

2. Contoh Implementasi di ALICE 3 (Count Loop)

Skenario: Membuat karakter bergerak mengelilingi lapangan persegi 4 sisi.

Alice 3 — Count Loop Block 
count 4 {
    this.alice.move(Direction.FORWARD, 2.0);
    this.alice.turn(Direction.RIGHT, 0.25);
}

Penjelasan Cara Kerja:
Blok di atas menggunakan count 4. Di dalam blok terdapat 2 perintah: maju 2 meter dan berbelok ke kanan 0.25 putaran (90 derajat). Komputer mengulang kedua perintah ini sebanyak 4 kali putaran, sehingga karakter membentuk lintasan persegi empat dan kembali menghadap ke arah awal. Tanpa loop, kita harus menulis 8 baris instruksi yang sama berulang kali.

3. Contoh Implementasi di Java (For Loop)

Java For Loop 
for (int i = 1; i <= 5; i++) {
    System.out.println("Latihan visual ke-" + i);
}
