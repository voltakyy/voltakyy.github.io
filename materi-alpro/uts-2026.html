📌 Soal 1: Analisis Standar Deviasi & Perbaikan Algoritma (Bug Fixing)

Bobot: 35 Poin · Analisis & Desain Algoritma
📝 Teks Asli Soal Ujian:

Dalam analisis data, standar deviasi digunakan untuk mengukur sebaran data terhadap nilai rata-ratanya. Diberikan kumpulan N data berupa array X = [x₀, x₁, ..., x_{N-1}]. Formula untuk menghitung rata-rata (x̄) dan standar deviasi sampel (s) adalah sebagai berikut:

1. Rumus Rata-rata (Mean Sample):
x̄ = (1 / N) * ∑ᵢ₌₀^{N-1} xᵢ
2. Rumus Standar Deviasi Sampel (Sample Standard Deviation):
s = √[ (1 / (N - 1)) * ∑ᵢ₌₀^{N-1} (xᵢ - x̄)² ]

Seorang mahasiswa membuat algoritma untuk menghitung standar deviasi tersebut. Namun, setelah diuji, hasil perhitungan algoritma tersebut selalu salah. Perbaiki algoritma tersebut dan tulis ulang secara lengkap dan beri penjelasan singkat.

❌ Algoritma Asli Mahasiswa (Mengandung Bug & Kesalahan Fatal):

FUNCTION HitungStandarDeviasi(X, N)
# X adalah array data dan N adalah jumlah data
START
  # Hitung total dan rata-rata keseluruhan data
  FOR i = 0 TO N - 1
    total <- total + X[i]        # ⚠️ BUG 1: Variabel 'total' tidak diinisialisasi nilai awalnya!
  END FOR
  rata_rata <- total / N

  # Hitung akumulasi selisih kuadrat dari rata-rata
  total_kuadrat <- 0
  FOR i = 0 TO N                 # ⚠️ BUG 2: Batas 'TO N' melampaui indeks array (Index Out of Bounds)!
    selisih <- X[i] - rata_rata
    total_kuadrat <- total_kuadrat + (selisih * selisih)
  END FOR

  # Hitung akar kuadrat varians dan kembalikan hasil
  varians <- total_kuadrat / (N - 1)
  s <- varians ** 0.5
  RETURN                         # ⚠️ BUG 3: RETURN kosong tanpa mengembalikan nilai s!
ENDFUNCTION

🔍 Bedah Kritis 4 Penyebab Algoritma Selalu Salah:

Titik Kesalahan Baris Rusak Konsekuensi Error / Dampak Fatal Perbaikan yang Tepat
Bug 1: Akumulator Tanpa Inisialisasi FOR i = 0 TO N - 1
  total <- total + X[i]		 Variabel total langsung dibaca nilainya pada iterasi pertama padahal belum diberi nilai awal. Di Python akan melempar NameError: name 'total' is not defined. Pada bahasa kompilasi (C/C++), ia akan berisi garbage value sehingga nilai rata-rata melenceng liar. Wajib menambahkan inisialisasi:
total <- 0 tepat sebelum loop pertama.
Bug 2: Off-by-One / Index Out of Bounds FOR i = 0 TO N (pada loop kedua) Array X berukuran N memiliki indeks sah dari 0 sampai N - 1. Menjalankan loop sampai N berarti ada N + 1 perulangan, yang akan memicu IndexError: list index out of range saat mengakses X[N]. Selain itu, jika tidak crash, perhitungan selisih kuadrat akan menjumlahkan elemen fiktif ke-(N+1) yang merusak rumus varians. Ubah batas perulangan menjadi:
FOR i = 0 TO N - 1 (sama seperti loop pertama).
Bug 3: Return Value Kosong RETURN Fungsi tidak mengembalikan hasil perhitungan apa pun (di Python bernilai None). Program pemanggil tidak akan pernah mendapatkan nilai standar deviasi s yang telah dihitung dengan susah payah. Ubah menjadi:
RETURN s agar nilai standar deviasi dikembalikan kepada pemanggil.
Bug 4 (Edge Case): Pembagian dengan Nol varians <- total_kuadrat / (N - 1) Jika data sampel hanya berjumlah 1 (N = 1) atau kosong (N = 0), maka (N - 1) = 0. Ini akan menyebabkan crash seketika karena ZeroDivisionError. Tambahkan validasi awal (guard clause):
IF N <= 1 THEN RETURN 0 (karena standar deviasi memerlukan minimal 2 data sampel).

✅ Algoritma yang Telah Diperbaiki Secara Lengkap (Pseudocode Sempurna):

FUNCTION HitungStandarDeviasi(X, N)
# X adalah array data dan N adalah jumlah data
START
  # 0. Validasi kondisi batas (mencegah ZeroDivisionError jika N <= 1)
  IF N <= 1 THEN
    RETURN 0
  END IF

  # 1. Inisialisasi akumulator total dan hitung rata-rata
  total <- 0
  FOR i = 0 TO N - 1
    total <- total + X[i]
  END FOR
  rata_rata <- total / N

  # 2. Inisialisasi total selisih kuadrat dari rata-rata (indeks 0 s.d. N - 1)
  total_kuadrat <- 0
  FOR i = 0 TO N - 1
    selisih <- X[i] - rata_rata
    total_kuadrat <- total_kuadrat + (selisih * selisih)
  END FOR

  # 3. Hitung varians sampel dan akar kuadrat (standar deviasi)
  varians <- total_kuadrat / (N - 1)
  s <- varians ** 0.5

  # 4. Kembalikan nilai hasil standar deviasi
  RETURN s
ENDFUNCTION

🐍 Implementasi Program Python Bersih & Terverifikasi:

def hitung_standar_deviasi(X, N):
    """
    Menghitung rata-rata dan standar deviasi sampel data X.
    Parameter:
      X (list): daftar bilangan numerik
      N (int): jumlah elemen data (len(X))
    Mengembalikan:
      float: nilai standar deviasi sampel (s)
    """
    # 0. Penanganan jumlah data tidak mencukupi untuk varians sampel
    if N <= 1:
        return 0.0

    # 1. Hitung total dan rata-rata
    total = 0
    for i in range(N):
        total += X[i]
    rata_rata = total / N

    # 2. Akumulasi jumlah kuadrat selisih
    total_kuadrat = 0
    for i in range(N):
        selisih = X[i] - rata_rata
        total_kuadrat += selisih * selisih

    # 3. Hitung varians sampel dan standar deviasi
    varians = total_kuadrat / (N - 1)
    s = varians ** 0.5
    return s


# === CONTOH PENGUJIAN / DRY RUN ===
data_uji = [4, 8, 6, 5, 7]
n_data = len(data_uji)

hasil_s = hitung_standar_deviasi(data_uji, n_data)
print(f"Data: {data_uji}")
print(f"Jumlah Sampel (N) : {n_data}")
print(f"Standar Deviasi (s) : {hasil_s:.4f}")
# Output: Standar Deviasi (s) : 1.5811

Misalkan diberikan sampel data X = [4, 8, 6, 5, 7] dengan N = 5:

  • Tahap 1 (Rata-rata): Total = 4 + 8 + 6 + 5 + 7 = 30. Rata-rata x̄ = 30 / 5 = 6.0.
  • Tahap 2 (Selisih Kuadrat):
    Indeks (i)Nilai X[i]Selisih (X[i] - x̄)Kuadrat Selisih (X[i] - x̄)²
    044 - 6.0 = -2.0(-2.0)² = 4.0
    188 - 6.0 = +2.0(+2.0)² = 4.0
    266 - 6.0 = 0.0(0.0)² = 0.0
    355 - 6.0 = -1.0(-1.0)² = 1.0
    477 - 6.0 = +1.0(+1.0)² = 1.0
    Jumlah Total Kuadrat (∑):10.0
  • Tahap 3 (Varians): varians = 10.0 / (5 - 1) = 10.0 / 4 = 2.5.
  • Tahap 4 (Akar Kuadrat): s = √2.5 ≈ 1.58113883. Hasil terbukti identik dengan modul statistics.stdev bawaan Python!

📌 Soal 2: Algoritma Denda Keterlambatan & Simulasi NIM

Bobot: 30 Poin · Perulangan WHILE & I/O
📝 Teks Asli Soal Ujian:

Terdapat algoritma berikut ini:

START
  INPUT hari_terlambat
  total_denda <- 0
  hari <- 1
  WHILE hari <= jumlah_hari DO
    total_denda <- total_denda + 2000
    hari <- hari + 1
  END WHILE
  OUTPUT total_denda
END

Pertanyaan:
a. Terjemahkan algoritma menjadi program Python.
b. Jika program dijalankan dan input hari terlambat sama dengan dua digit terakhir NIM anda, tentukan tampilan program.

💡 Catatan Telaah Kritis Algoritma:

Pada naskah asli, terdapat sedikit inkonsistensi penamaan variabel: baris awal menginput hari_terlambat, namun di baris perulangan tertulis WHILE hari <= jumlah_hari DO. Dalam konteks logika algoritma, variabel jumlah_hari tersebut mengacu langsung pada hari_terlambat. Menyebutkan catatan ini pada lembar jawaban menunjukkan ketelitian analitis tingkat tinggi!

a. Terjemahan Algoritma Menjadi Program Python:

Program Python ditulis secara presisi mengikuti setiap baris pseudocode di atas: 

# Program Menghitung Denda Keterlambatan
# Terjemahan resmi dari pseudocode

# 1. INPUT hari_terlambat
hari_terlambat = int(input("Masukkan hari terlambat: "))

# 2. Inisialisasi akumulator total_denda dan pencacah hari
total_denda = 0
hari = 1

# 3. WHILE hari <= hari_terlambat DO
while hari <= hari_terlambat:
    total_denda = total_denda + 2000
    hari = hari + 1

# 4. OUTPUT total_denda
print("Total denda:", total_denda)

Penjelasan Baris Program:

  • int(input(...)): Menerima input dari pengguna dan mengubah tipe datanya dari teks (string) menjadi bilangan bulat (integer).
  • total_denda = 0: Mengatur nilai awal saldo denda sebesar 0 rupiah.
  • hari = 1: Inisialisasi variabel pencacah iterasi dimulai dari hari ke-1.
  • while hari <= hari_terlambat:: Blok perulangan akan terus berputar selama nilai hari belum melampaui jumlah hari terlambat.
  • total_denda = total_denda + 2000: Menambahkan denda sebesar Rp 2.000 per hari keterlambatan.
  • hari = hari + 1: Melangkah ke hari berikutnya (mencegah loop tak hingga / infinite loop).
  • print(...): Mencetak hasil akhir akumulasi denda ke layar konsol.

b. Penentuan Tampilan Program Sesuai Dua Digit Terakhir NIM:

Setiap mahasiswa akan memiliki tampilan program yang unik tergantung dua digit terakhir dari Nomor Induk Mahasiswa (NIM) masing-masing. Rumus matematis total dendanya adalah:

Total Denda = (Dua Digit Terakhir NIM) × Rp 2.000

Contoh Kasus 1: NIM L200260089 (Dua digit terakhir = 89)

Jika mahasiswa dengan NIM berakhiran 89 menjalankan program:

  • Jumlah iterasi: Loop while berputar sebanyak 89 kali (hari 1 sampai hari 89).
  • Akumulasi denda: 89 × 2000 = 178000.
  • Tampilan persis pada layar terminal/konsol:
Masukkan hari terlambat: 89
Total denda: 178000

Contoh Kasus 2: NIM L200240005 (Dua digit terakhir = 05 atau 5)

Jika input adalah 5 hari:

  • Jumlah iterasi: 5 kali perulangan.
  • Akumulasi denda: 5 × 2000 = 10000.
  • Tampilan layar konsol:
Masukkan hari terlambat: 5
Total denda: 10000

Contoh Kasus Khusus: NIM L200240100 (Dua digit terakhir = 00)

Jika input adalah 0:

  • Kondisi hari <= hari_terlambat (yaitu 1 <= 0) langsung bernilai False sejak awal.
  • Blok di dalam while tidak dieksekusi sama sekali (0 iterasi).
  • Tampilan layar konsol:
Masukkan hari terlambat: 0
Total denda: 0

📌 Soal 3: Tracing Variabel String Slicing & Operator Precedence 2026

Bobot: 35 Poin · String Manipulation & Arithmetic
📝 Teks Asli Soal Ujian:

Pada program di bawah ini, gantilah teks 'L200101010' dengan NIM saudara sendiri. Berapakah nilai yang tersimpan di variabel a, b, c, e, f, g, dan h setelah program dijalankan? (Catatan: variabel d dihitung sebagai perantara). 

Z = 'L200101010' # ganti L200101010 dengan NIM saudara
a = Z[1::4]
b = 2 * a + Z[-2]
c = int(a) + 2
d = c % 10 - 3
e = c // 20 - 15
f = d > 5 or e < 0
g = e + d ** 2
h = c - 2 * e

📏 Peta Indeks String NIM (Format 10 Karakter):

Setiap karakter dalam string Z memiliki indeks positif (dari kiri: 0 sampai 9) dan indeks negatif (dari kanan: -10 sampai -1). Kotak hijau menunjukkan karakter yang terambil oleh ekspresi slicing Z[1::4]:

🔬 Analisis Eksekusi Baris demi Baris:

1. a = Z[1::4]

Slicing string berformat [start:stop:step] dengan start = 1 dan lompatan step = 4. Mengambil karakter pada indeks:
• Indeks 1: Z[1]
• Indeks 1 + 4 = 5: Z[5]
• Indeks 5 + 4 = 9: Z[9]
Hasilnya berupa string 3 karakter: a = Z[1] + Z[5] + Z[9].
Contoh pada NIM default 'L200101010': Z[1]='2', Z[5]='0', Z[9]='0' → a = '200' (tipe: str).

2. b = 2 * a + Z[-2]   ⚠️ PERANGKAP DUPLIKASI STRING

Karena a bertipe string, operator * adalah replikasi teks (string repetition), BUKAN perkalian angka!
• 2 * a menduplikasi string a dua kali (misal 2 * '200' = '200200').
• Z[-2] adalah karakter indeks ke-2 dari belakang (indeks 8), misal '1'.
• Operator + menggabungkan kedua string (concatenation).
Hasil: b = '2002001' (tipe: str, berupa string 7 karakter!).

3. c = int(a) + 2

String a dikonversi menjadi bilangan bulat melalui int(a), lalu ditambah 2.
Contoh: int('200') + 2 = 202 (tipe: int).

4. d = c % 10 - 3   (Variabel Perantara)

Sesuai presedensi operator aritmatika, operasi modulo % dikerjakan terlebih dahulu daripada pengurangan -.
• c % 10 menghasilkan sisa pembagian 10 (digit terakhir dari c, misal 202 % 10 = 2).
• Lalu dikurangi 3: 2 - 3 = -1 (tipe: int).

5. e = c // 20 - 15

Operator // adalah pembagian bulat (*floor division*), memiliki prioritas lebih tinggi dari pengurangan -.
• c // 20 (misal 202 // 20 = 10).
• Lalu dikurangi 15: 10 - 15 = -5 (tipe: int).

6. f = d > 5 or e < 0

Operator relasional > dan < dievaluasi mendahului operator logika or:
• Evaluasi kiri: d > 5 → -1 > 5 bernilai False.
• Evaluasi kanan: e < 0 → -5 < 0 bernilai True.
• Operasi disjungsi: False or True menghasilkan True (tipe: bool).

7. g = e + d ** 2

Operator pemangkatan ** memiliki presedensi paling tinggi:
• d ** 2 dihitung pertama kali: (-1)² = 1.
• Lalu dijumlahkan dengan e: -5 + 1 = -4 (tipe: int).

8. h = c - 2 * e

Perkalian 2 * e dihitung terlebih dahulu: 2 * (-5) = -10.
Pengurangan dengan bilangan negatif menjadi penjumlahan: c - (-10) = 202 + 10 = 212 (tipe: int).
