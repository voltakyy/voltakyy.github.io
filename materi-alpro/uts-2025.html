ðŸ“Œ Soal 1: Konsep Dasar Algoritma & Pemrograman

Bobot: 25 Poin (CPMK 1)

1.a. Apa yang Anda ketahui dari Algoritma? (Skor: 5)

Etimologi: Kata Algoritma berasal dari nama ilmuwan matematika muslim terkemuka Abu Ja'far Muhammad bin Musa Al-Khawarizmi.
Definisi Formal: Algoritma adalah urutan langkah-langkah logis, terstruktur, dan berhingga yang disusun secara sistematis untuk memecahkan persoalan komputasi tertentu.

5 Kriteria Mutlak Donald E. Knuth: 1. Finiteness (pasti berakhir), 2. Definiteness (langkah pasti & tidak ambigu), 3. Input (nol atau lebih data masuk), 4. Output (minimal satu solusi hasil), dan 5. Effectiveness (setiap langkah efektif & wajar).

1.b. Menurut Anda, apakah algoritma sama dengan flowchart? Jelaskan! (Skor: 5)

Jawaban: TIDAK SAMA.
Algoritma adalah gagasan logika atau urutan langkah pemecahan masalahnya (konsep abstrak). Sedangkan Flowchart adalah salah satu teknik representasi visual/grafis dari algoritma menggunakan simbol geometris baku (oval terminator, jajar genjang I/O, persegi panjang proses, belah ketupat keputusan).

1.c. Menurut Anda, bagaimana struktur program yang baik? (Skor: 5)

Struktur program yang baik berpegang pada prinsip Pemrograman Terstruktur (Structured Programming) dengan 3 konstruksi alur kendali:

  1. Runtunan (Sequence): Kode dieksekusi runtut baris per baris dari atas ke bawah.
  2. Percabangan (Selection): Mengatur keputusan alur logika berdasarkan kondisi boolean (if-elif-else).
  3. Perulangan (Iteration): Mengulang blok kode selama kondisi bernilai True (for / while).

Kualitas pelengkap: Modular (dipecah dalam fungsi), Readable (nama variabel bermakna & indentasi PEP 8), dan Robust (mampu menangani kesalahan input).

1.d. Perintah & Contoh Program Python: Meminta 2 Input, Menampilkan Input, dan Menghitung Hasilnya (Skor: 10)

# 1. Meminta 2 input pengguna (konversi tipe data str ke float)
angka1 = float(input("Masukkan angka pertama : "))
angka2 = float(input("Masukkan angka kedua   : "))

# 2. Menampilkan masing-masing inputan
print("
--- DATA INPUT ---")
print("Data input pertama :", angka1)
print("Data input kedua   :", angka2)

# 3. Menghitung hasil keduanya
penjumlahan = angka1 + angka2
perkalian   = angka1 * angka2

print("
--- HASIL PERHITUNGAN ---")
print(f"Hasil Penjumlahan ({angka1} + {angka2}) = {penjumlahan}")
print(f"Hasil Perkalian   ({angka1} * {angka2}) = {perkalian}")

ðŸ“Œ Soal 2: Sistem Kasir Minimarket & Flowchart Diskon 10%

Bobot: 40 Poin (CPMK 1)
Kasus: Kasir memasukkan harga setiap barang dan jumlah barang yang dibeli. Setelah semua data dimasukkan, sistem menghitung total harga dan memberikan potongan 10% jika total pembelian lebih dari Rp 100.000.

2.a. Algoritma Pseudocode (Skor: 20)

ALGORITMA Kasir_Minimarket_Diskon10
DEKLARASI:
    harga_barang, jumlah_beli : Riil
    subtotal, total_belanja   : Riil
    diskon, total_bayar       : Riil
    ulang                     : Karakter ('y' atau 't')

DESKRIPSI:
    1. total_belanja <- 0
    2. ulang <- 'y'
    3. SELAMA ulang = 'y' ATAU ulang = 'Y' LAKUKAN:
           INPUT harga_barang
           INPUT jumlah_beli
           subtotal <- harga_barang * jumlah_beli
           total_belanja <- total_belanja + subtotal
           INPUT ulang ("Tambah barang lain? y/t: ")
    4. JIKA total_belanja > 100000 MAKA:
           diskon <- 0.10 * total_belanja
       SELAIN ITU:
           diskon <- 0
    5. total_bayar <- total_belanja - diskon
    6. OUTPUT total_belanja, diskon, total_bayar
    7. SELESAI
