Soal A.1: Tiga Perintah Dasar Komputer (10-15 Baris Tulisan Tangan) (Skor: 30)

Setiap program komputer imperatif pada dasarnya bekerja melalui siklus 3 perintah dasar:

  1. Perintah Meminta Data (Input): Membaca masukan dari luar (keyboard/file). Pada Python menggunakan perintah input() yang mengembalikan nilai berupa tipe string.
  2. Perintah Menyimpan & Memproses Data (Assignment & Processing): Mengikat nilai ke memori variabel dengan operator penugasan = dan memanipulasinya dengan kalkulasi aritmatika.
  3. Perintah Menampilkan Data (Output): Menyajikan hasil olahan ke layar konsol menggunakan perintah print().
# Contoh 3 Perintah Dasar Python
nama = input("Siapa nama Anda? ")           # 1. Meminta data
pesan = "Selamat datang di UMS, " + nama    # 2. Menyimpan & memproses
print(pesan)                                # 3. Menampilkan data

Soal A.3: Menerjemahkan Algoritma Koleksi ke Kode Python (Skor: 30)

def hitung_jumlah(kol):
    """
    Menerjemahkan Algoritma:
    1. jml <- 0
    2. Untuk setiap x dalam kol: jml <- jml + x
    3. RETURN jml
    """
    jml = 0
    for x in kol:
        jml = jml + x
    return jml

# Pengujian
angka = [10, 25, 30, 45, 50]
print("Total jumlah elemen:", hitung_jumlah(angka)) # Output: 160

Studi Kasus Nota Kopi Makmur (Skor: 90)

Data Kasus Nota: 4 jenis kopi (Arabika 10kg @80k = 800k, Robusta 15kg @65k = 975k, Liberika 5kg @90k = 450k, Excelsa 8kg @75k = 600k). Subtotal: Rp 2.825.000. Diskon 3% karena total belanja di atas Rp 1.000.000 (Diskon: Rp 84.750). Total Bayar: Rp 2.740.250.

Program Lengkap Python Kasir Nota Pembelian Kopi:

# Program Pembuatan Nota Pembelian Kopi (PT Kopi Makmur)
keranjang = []
total_pembelian = 0

print("=== INPUT BARANG PT KOPI MAKMUR ===")
while True:
    nama = input("Nama Kopi         : ")
    if not nama.strip():
        break
    qty = float(input("Jumlah (Kg)       : "))
    harga = float(input("Harga Satuan (Rp) : "))
    
    subtotal = qty * harga
    total_pembelian += subtotal
    keranjang.append({"nama": nama, "qty": qty, "harga": harga, "subtotal": subtotal})
    
    ulang = input("Ada item kopi lain? (y/t): ").strip().lower()
    if ulang != 'y':
        break

# Percabangan Diskon 3% jika total pembelian > 1.000.000
if total_pembelian > 1000000:
    persen = 3
    diskon = 0.03 * total_pembelian
else:
    persen = 0
    diskon = 0

total_bayar = total_pembelian - diskon

# Cetak Struk Nota
print("
" + "="*50)
print("              NOTA PEMBELIAN")
print("              PT KOPI MAKMUR")
print("="*50)
for i, item in enumerate(keranjang, 1):
    print(f"{i}. {item['nama']:<16} {int(item['qty'])} Kg x Rp {item['harga']:>8,.0f} = Rp {item['subtotal']:>9,.0f}")
print("-"*50)
print(f"Jumlah Pembelian : Rp {total_pembelian:>12,.0f}")
print(f"Diskon ({persen}%)      : Rp {diskon:>12,.0f}")
print(f"Total Pembayaran : Rp {total_bayar:>12,.0f}")
print("="*50)
print("Metode Pembayaran: Transfer Bank")
